# BeyondChats Frontend — React + Vite

This directory contains the frontend client for **BeyondChats**, built with React 18, Vite, and Tailwind CSS.

For complete project documentation, installation instructions, setup guides, and screenshots, please refer to the main [Root README.md](../README.md).

## Quick Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
